## 二、冻结预算(生效,实验后不得放宽)

| 预算项 | 冻结值 | 说明 |
| --- | --- | --- |
| 机械开销(每 hook/观察点) | ≤ 100ms 本地计算 | 不做全仓扫描;只读既有持久事实 |
| 模型审查调用 | 每任务 ≤ 3 次新增模型调用 | 仅限冻结触发节点;普通工具调用零新增 |
| 单次审查输入 | ≤ 2k tokens 摘要 | 长日志留文件,按需回读 |
| 每问题自动纠偏轮数 | ≤ 2 轮 | 无进展转人;不靠重试稀释失败 |
| 监督引入额外墙钟 | ≤ 任务时长 5% | 超出即降级为纯记录(shadow) |
| 预测工件大小 | ≤ 200 行/任务 | 语义影响,不是文件清单 |

## 三、冻结的触发节点(B2)

1. 改变公共接口 / 状态迁移 / 共享资源之前;
2. 完成一个逻辑改动之后;
3. 发现新依赖时;
4. 验证结果与预测矛盾时;
5. 进入昂贵测试 / 安装 / 交付之前。
信号未变化不重复触发。

## 四、证据身份与失效规则

| 输入 | 身份 | 失效规则 |
| --- | --- | --- |
| 代码 | git blob/内容 sha(沿用 generation/tree_sha 体系) | 身份变化 → 相关预测标 `stale`,需重新判断,不自动作废 |
| 测试 | evidence_key + head + workspace_sha(sulde-test-evidence-v2) | 不匹配 → 不可复用为当前结论 |
| 依赖/环境 | python environment fingerprint | 变化 → 运行类证据失效 |
| 预测工件 | 版本化追加,绑定 task/run/session + 合同版本 + 源码身份 | 只增不改;修订须写新证据与理由 |

## 五、接入边界

- **受管子任务**(agent-runtime 启动):stdin 单次写入后关闭——运行中唯一动作是
  interrupt;纠偏经 `managed_run_monitor` 边界(interrupt + 下一 attempt 带上修正)。
- **交互式任务**:投递仅限 Stop 上下文追加 / PreToolUse 决策 / UserPromptSubmit 检测 /
  codex PermissionRequest;无即时注入,过期/跨会话消息由 request_sha256/身份绑定拒绝。
- **B4 样本分离**:公开集 = 方案 §7 场景表;保留集(独立变体+正常反例)由协调端持有,
  执行端不可见。
- **协议层**可用假 provider 验证;真实 Agent 行为证据需已授权真实宿主运行,未完成前
  只能声明"协议/接线通过"。
