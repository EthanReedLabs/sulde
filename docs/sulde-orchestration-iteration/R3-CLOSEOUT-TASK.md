## 5. A1：恢复入口的 fence 生命周期

1. 普通安装自动恢复和 `--recover-only` 使用一致、可验证的事务匹配和清理语义。
2. 恢复成功且 fence 属于该事务，方可清除对应 fence；随后验证租约准入恢复。
3. 恢复失败、身份不匹配、损坏或不可解析不能按成功处理或盲目删除。
4. 覆盖 fence 发布之后、活动事务持久化之前的中断窗口。无活动事务不等于安全删除；
   应按现有可验证安装事实给出有界恢复/明确诊断，不仅要求“再安装一次”。
