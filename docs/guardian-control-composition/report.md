## 行为变化

新增有界、非执行的 POSIX shell 计划：最多 64 KiB / 64 步。支持明确 argv 的
`&&`、`||`、`;`、换行、管道及明确文件重定向。引号中的操作符仍是参数数据。
每个可能执行的步骤在同一权限快照下预检，通过后交回原 shell 执行，不自行调度、
重试或改变短路语义。

- 可组合：可信 Guardian 只读查询、help、精确绑定当前合同和 session 的 Skill
  登记/结算、既有 Agent 路由的 verification reconciliation。
- 可配合：已证明只读的过滤器、受限 stdin JSON formatter、目标完整的
  touch / mkdir / tee，以及仍满足既有人类精确路径卡的删除操作。
- 重定向输出按实际本地写路径检查，不借控制命令身份豁免。
- unified exec 的多个子调用保留全部控制决策，不能由第一个只读调用覆盖后续拒绝。
- 原生审批、任务/权限上下文转换、密封维护调用仍走各自精确入口；旧的单条授权
  不自动覆盖整段程序。组合不能自授予新权限。
- 动态展开、eval、shell 状态修改、后台任务、无法证明全部效果的脚本暂不纳入。
  拒绝说明具体步骤/原因，不把组合语法本身描述为破坏性操作。
- 拒绝发生在执行前时，拒绝该组合但不暂停整个 lane、不制造执行债务。
  已执行而缺失 Pre 证据的情形仍保留 gap，不借此清除安全事实。
- 组合 exit 0 不代表各步骤成功；子步骤保持 `not_observed` / `success=null`，
  只让真实 Hook 和 CLI 自身日志记录实际发生的动作。

普通调用只增加轻量入口判断，不加载组合解析器；未引入依赖、普通调用摘要扫描、
新事务或后台服务。Git / Figma 执行域规则不变。Windows 保留既有行为，未宣称已
完成 Windows shell 组合或真实宿主验收。

## 执行中发现的问题与处理

1. 引号内分号文件名被旧目标提取逻辑切断：修复为无非引号控制符时按单条 argv
   提取，补回归；未重写普通 shell 全部分类。
2. 广义“只读程序名”不足以证明过滤器安全：新增 sort 输出/外部程序、find -exec、
   sed 写入、opaque Python、cp 目标选项、printf -v / %n 反例；`%%n` 仍是数据。
3. 原生 fixture 用错 show 的位置参数，及外层隔离标记在候选环境切换后丢失：
   分别改为 `show --contract` 和提前保存外层隔离状态，未绕过生产 Guardian。
4. 一次既有 native 测试在有效 proof 后遇到临时 plugins 目录 cleanup
   `Directory not empty`；后续重新验证通过。未趁机修改不相关生产清理实现；
   其稳定根因仍为 inconclusive。
5. 首次性能测试旧基线在 45 s 触发采样进程总超时。后续完成的对照表明每类
   约 320 ms、两侧总计 900 次计时调用，原总超时不足。仅将每侧总采样时限改为
   180 s，单次预算不变；未声称已经剖析 320 ms 的内部成本来源。
6. 早期未隔离批准执行遇到 macOS 嵌套 sandbox 拒绝；使用正式隔离 runner
   及原生宿主授权执行，不通过手工合成成功记录解决。

保留的失败 run：`20260909T070028.397659-abc6c21144cf`（隔离门禁）、
`20260909T070026.271798-667977a8711d`（native fixture / cleanup）、
`20260909T073740.882960-cfe28c584316`（基线采样超时）。后续成功不抹去这些事实。

## 沉淀候选（Layer1，未写入共享 KB）

- 问题类型：bug-fix / workflow / regression。
- 任务目标与真实预期：允许能证明完整权限和效果的高效拼接，不再仅因语法拒绝。
- 触发场景：可信控制命令与查询过滤、Skill 登记或本地动作组合。
- 症状：原先“可信控制命令必须单个精确调用”的粗规则产生无必要中断。
- 已确认根因：把控制入口身份误当成整个 shell 程序的权限单位，缺少逐步权限
  预检和组合结果语义；若直接豁免又会把未知/高风险尾部当作可信只读。
- 已排除：并非 Codex CLI 无法执行管道/顺序控制；真实宿主候选测试已完成。
- 证据状态：上述有限实现及测试结论 verified；全 shell 安全性和整体提速
  比例 inconclusive，不作扩大结论。
- 正确做法：有界静态计划、逐步预检、原 shell 执行、拒绝不暂停、真实效果才记账。

| 样本 | 内容 | 固定预期 | 判定原因 | 来源 |
