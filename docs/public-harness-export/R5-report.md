## 沉淀候选（仅任务内，不外写）

证据 verified，范围为上述测试夹具：代码文件可同时包含可公开的实现与不可公开的
历史任务/观测数据；隐私判断必须看内容和来源，不能只看后缀或扫描命中数量。

- 路由正例：测试内包含从真实任务拷贝的标题、基线摘要或观测账本。

- 执行合格例：仅公开投影生成合成输入，保留真实 parser/拒绝链，逐条摘要留证。
- 执行失败例：复制历史正文、删掉安全断言、全局豁免测试目录或把合成验证称为 live。
