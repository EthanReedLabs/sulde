L3 前冻结生产旧代际及回滚事实、新 artifact 身份、确切受影响宿主/cohort、
维护期限和验证清单；管理员准备步骤合并为有界清单，普通安装/归档不作为 root 运行。
独立执行器和恢复入口不得依赖将被关闭或故障的 Guardian/当前协调会话。
先证明独立恢复入口可达、回滚输入可用，再进入正式写入；不足则 L3 不启动。

人只通过当前宿主的原生界面确认真正的高风险维护范围。实际安装还需其精确
一次性绑定，不复制测试批准，不由 Agent 点击 Allow。Agent 完成已批准机械步骤。
声明只能覆盖已知宿主，不能承诺阻止任意未来启动的新会话。

序列：真实 preflight → 精确原生批准 → 原任务保全/获准停止 → frozen worker →
事务安装 → scheduler/readiness/信任回读 → 真实正反 Hook（负例执行前拒绝）→
旧线程续接或明确需重载的宿主恢复。Pre/Post 分别绑定 loaded_module_generation
与 artifact_generation，各自匹配本次发布，不要求两种字段互等。

前置失败：零生产变更，保留 old production；写入后失败：按同一事务的独立恢复
入口恢复精确旧代际并回读。回滚失败必须报告 recovery_required，不能报 ready。
安装事务提交不等于 L3 ready；真实宿主失败即使事务已提交，也进入已批准恢复流程。
验证用最小确定性探针，不在生产重跑整个源码测试集或付费多样本对照。
