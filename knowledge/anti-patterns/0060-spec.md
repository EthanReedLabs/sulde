# 0060 双端 Spec 进度不同步 → 跨端漂移视觉/行为不一致

- **平台**:协调端(双端对齐类)
- **复发次数**:5+

## ❌ 错误 — 症状

- 登录 modal 形态:iOS 已多次迭代(白色 50% → 黑色毛玻璃)/ Android 一直整页 → 双端不一致多天
- 登录 modal dimmer 视觉契约:iOS 黑色毛玻璃 / Android 待对齐
- App Icon mark-only 形态:iOS handoff 假设错(整 logo 居中)/ Android 同样错(60% 宽铺满)→ 双端同期协调端给同样错指令
- 登录态广播架构:iOS 部分广播 / Android Fragment 手动 query — 双端各自漂移

## 为什么错(根因)

协调端无双端 Feature 进度对照表:
- 任一端 commit / handoff 后,协调端没 audit 另一端是否需 sync
- 双端 task md 派出时没"双端进度同步段"
- 用户跨端实测才暴露(一端 OK / 另一端滞后)

## ✅ 正确 — 修法

`dual-platform-progress.md` 文件 + 协调端 CLAUDE.md 审单步骤硬约束:

1. **新建 `dual-platform-progress.md`** 列 Feature × iOS × Android × 同步状态
2. **协调端写 task md 前必 audit 对照表**
3. **任一端改 → 立即更新对照表 + audit 另一端是否需 sync**
4. 状态符号:✅ / 🟡 / ⚠️(滞后)/ ⏳(pending)/ N/A

## 判定线

协调端写双端 task md 但未引用 `dual-platform-progress.md` 状态 → 违规。

## lint 状态

- 协调端:`dual-platform-progress.md` 已建 + CLAUDE.md 审单步骤硬约束
- Dev:N/A

## 关联

- 协调端写双端 task md 未硬约束 Spec 一致 — 父类反模式
- 跨端默认 Real 路径不对称
- 协调端 CLAUDE.md 审单步骤
