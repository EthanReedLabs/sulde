# 0032 — 首启不弹 GDPR 同意弹窗

- **平台**:Android（合规）
- **复发次数**:0（已修复）
- **lint 状态**:运行时逻辑，无法静态 lint

## ❌ 错误

仅在 deep link 场景检查 Consent 状态，冷启动（无 deep link）直接进主页不弹同意弹窗 — 违反 GDPR 首启必明示同意要求。

```kotlin
// MainActivity.handleDeepLink() 里判断 needsConsent → 弹窗
// 但冷启动（无 deep link）走 onCreate 主路径，跳过了 handleDeepLink → 不弹
```

## 为什么错

- GDPR 强制"首次启动主动请求明示同意"，冷启动是最常见的首启路径
- 只在 deep link 场景检查 → 直接开 App 的用户永远没看到同意弹窗 → 默认收集数据 = 违规

## ✅ 正确

无论有无 deep link，`onCreate` 末尾（`savedInstanceState == null` 时）都要调 `ConsentDialog.showIfNeeded(...)`：

```kotlin
override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    // ...
    if (savedInstanceState == null) {
        ConsentDialog.showIfNeeded(supportFragmentManager, gdpr)  // ← 关键
    }
}
```

## lint 状态

- ❌ 无法静态 lint（涉及运行时逻辑）
- 合规子任务必须 E2E 验证冷启动是否弹 Consent
