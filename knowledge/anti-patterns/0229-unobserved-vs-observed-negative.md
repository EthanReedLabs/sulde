# 0229 — 把"观测不到"写成"观测到没有"

- **平台**:none

## ❌ 错误

一次差分实验、一轮采样或一份打点没有看到目标现象,结论直接写成终局判决:

```
打点覆盖 T0 -> T4 = 71ms(未覆盖 T4 -> T5) → 结论:"链路无瓶颈"
单次 A/B 差分未见收益                       → 结论:"该优化无效"
日志里没有异常堆栈                          → 结论:"没有崩溃"
抓包只抓到首个请求                          → 结论:"请求没有串行"
```

共同错误:把"我的观测手段没有覆盖到它"与"我观测到它是好的"合并成同一个结论,
并用终局性形容词(彻底 / 完全 / 不存在 / 无效 / 已排除)固化下来。

## 为什么

**观测结果是三态,不是二态。** 真实的三种状态是:观测到好、观测到坏、
观测不到(工具未覆盖 / 灵敏度不足 / 样本量为 1 / 采集失败)。二值化的报告没有
第三态的位置,它必然被静默并入前两态之一——而习惯上总是并入"好"。

**证据缺席只在观测手段确有发现能力时才构成不存在的证据。** "没看到"要升级为
"没有",前提是先证明"若存在,该手段必能看到":覆盖范围包含目标区间、灵敏度
高于目标量级、样本量足以让效应显著。这三条未说明时,缺席是零信息,不是否定。

**单次差分提供的是似然,不是判决。** 一次对照只够把先验往一个方向推一点,
对应的动作是调整置信度;终局性形容词等价于把后验直接钉死在 0 或 1,
后续出现的复现证据将无处安放,而本该继续排查的方向被提前关闭。

**盲区一旦写成既成事实,就会被下游当作已验证结论复用。** 后来者不再重测,
盲区固化成团队共识;纠正成本远高于当初老实标注一句"未观测"。

## ✅ 正确

**1. 三态显式落纸,盲区必须命名**

不留白、不默认为正常:

```
观测到好:T0 -> T4 = 71ms,工具 X,覆盖完整
观测到坏:主线程单帧 1.7s,工具 Y,可复现 3/3
观测不到:T4 -> T5 未打点,当前工具无法覆盖 → 待补测
```

**2. 结论句式携带证据量与置信度,而不是形容词**

```
❌ 该方向已排除 / 该优化无效
✅ 单次差分未见显著差异(n=1,灵敏度未标定)→ 该方向置信度下调,未排除
```

**3. 想把缺席写成否定,先补上发现能力的说明**

允许写"不存在"的最小前提是三行:覆盖范围包含目标、灵敏度优于目标量级、
样本量足够。写不出这三行,就只能写"未观测"。

**4. 终局性形容词需要多次可复现证据或机制层解释背书**

"彻底 / 完全 / 一定不 / 已排除"只在两种情况下可用:同一现象多次独立复现,
或已定位到机制层面的原因说明它为何不可能发生。

**5. 排除项单独成节,每条附证据、工具与阈值**

```
## 排除项
- 候选 A:实测占比 < 1%(工具 X,覆盖 T0-T5 全段,n=5)→ 排除
- 候选 B:未观测(工具 X 不覆盖该层)→ 未排除,待换工具
```

这样"排除"和"没查"在同一张表里也分得开,后续接手的人知道该从哪继续。

**6. 数值度量必须保留“缺失”这一态**

采样失败、权限不足或解析失败时，字段应使用 `null`/缺失值并附 `missing_reason`，同时让
依赖该字段的 gate 进入 `insufficient` 或失败态。禁止写成 `0`：零是一个真实观测值，
下游会把“没有证据”误读成“CPU 为 0 / 错误数为 0 / 延迟为 0”并错误放行。

schema、聚合器和展示层都要支持三态；平均值/比例计算不得把缺失样本补零，报告同时披露
有效样本数与缺失数。负向测试应让采集器故意失败，断言 gate 不会得到 PASS。
