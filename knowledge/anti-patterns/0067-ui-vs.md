# 0067 修复 UI 时不分类系统级 vs 业务级

- **平台**:双端
- **复发次数**:0

## ❌ 错误

发现"标题挤进状态栏",在当前页加 `paddingTop = 24dp` 当场了事。

## 为什么错

重复劳动 + 治标不治本 —— 多页同源问题各打各的补丁,系统级根因没修。

## ✅ 正确

先查"系统级问题清单":
- 是系统级 → 去底层(scaffold / 基类)修一次;
- 是业务级 → 当前页修。
