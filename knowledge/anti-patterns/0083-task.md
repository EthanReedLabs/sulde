# 0083 — 视觉对齐 task 误改业务链路

- **平台**:双端通用
- **复发次数**:1

## 症状

Dev 接到 ui-fix 类 task（改图标 / 颜色 / 字号 / 圆角 等纯视觉），实施时**误改业务行为**:
- click handler 被误删 / 误改 → 列表 item 点不响应
- 跳转链路被误改 → 列表点操作不跳转下一页
- store.send / Action / Intent dispatch 被误删 → 用户操作无反应
- nav graph / Route 被误改 → 跳错页

**典型实例**:Dev 改某列表卡片的图标 outline 时，意外断开了卡片点击 item 的跳转链路。编译 ✅ + handoff 自审 ✅ + diff stat 看着只是图标改动 — 但 runtime 行为破坏，真机验收时才发现"卡片点击不跳转"。

## 根因

1. Dev 在改视觉时**顺手 refactor / 简化代码**，误删 click handler / button action
2. enum 改动 / 类型替换时**触发未感知的 cascade 删除**（IDE 自动 fix-it 顺手删）
3. visual diff 看着干净（只动 visual modifier / drawable），但隐藏在 enclosing button / View 嵌套结构改了
4. **Dev 自审 + handoff 视觉对齐表**只对照设计真值，**没 audit 行为链路保留**

## 修法

### A. task md 加 `behavior_preservation` 段（协调端写 task 时必填）

```yaml
type: ui-fix
behavior_preservation:
  - "保留 onItemClick / Tap handler 不动"
  - "保留 store.send(.{create_tapped/itemSelected}) dispatch"
  - "保留 nav 跳转（本 task 仅改视觉，行为不动）"
```

### B. Dev 完工自审 +1 步:**git diff 行为链路 grep**

```bash
# 视觉 task 完工 commit 前必跑
git diff <commit_range> -- <修改文件> | grep -iE "onTap|onClick|setOnClickListener|store\.send|store\.intent|navigate|popToRoot|dismiss|onBackTapped|delegate"
# 命中 ≥ 1 行 = STOP，严肃 review 是否破坏行为链路
# 0 命中 = 安全
```

### C. handoff 必含"行为链路自审"段

```markdown
## 行为链路自审（ui-fix 必填）
- click handler:[列每个 button / list item 的 onClick / onTap 引用，实证保留]
- nav 链路:[列每个 store.send / navigate / route 调用，实证保留]
- state dispatch:[列 reducer / store 字段是否动]
- diff grep:`git diff` 内含 click/nav/state 关键词 = N 行 ✅（N=0 安全 / N>0 注解保留原因）
```

### D. verify 脚本 commit 子命令前置 lint

```bash
DIFF=$(git diff <base>..HEAD)
if echo "$DIFF" | grep -qiE "onTap|onClick|setOnClickListener|store\.send|navigate"; then
    echo "⚠️ 警告:diff 含行为链路关键词，确认是 ui-fix task 期望改动?"
    echo "$DIFF" | grep -iE "onTap|onClick|setOnClickListener|store\.send|navigate"
    read -p "继续 commit?（y/n） "
fi
```

## 判定线

ui-fix 类 task md 缺 `behavior_preservation` 段 / handoff 缺"行为链路自审"段 → 违规。

## lint 状态

- 候选 lint:`rules/043-ui-fix-no-handler-changes.sh`（grep diff 行为链路关键词）

## 关联

- 自发修复路径反模式（父类 — scope 扩散）
- handoff 流于声明（自审段流于"看着对齐设计真值"无实证行为）
