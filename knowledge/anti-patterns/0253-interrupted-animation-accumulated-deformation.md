# 0253 — 动画中断后在已有形变上再次累加

## 问题原型

选中指示器、拖动轮廓或过渡面板尚未完成形变，用户又改变目标。单次切换及终点都正常，
但连续快速改选后宽度或高度越来越大，超过承载区；若强制重置到旧稳态，又会在中断处跳变。
期望是从当前显示帧继续运动，保持连续且不超出设计允许的范围。

## ❌ 错误

- 每次重定向都把“当前宽度 + 新距离的拉伸量”当作新宽度，忽略当前帧已经含有旧拉伸。
- 只检查最终选中项和终点尺寸，不测中段、反向和连续中断。
- 为避免累积直接回到原始圆形再开动画，导致可见轮廓跳变。
- 用“无旧轮廓的首现”模型处理“已有轮廓移动”，或把剪辑切镜误作连续运动证据。

## 为什么错

当前显示值不是未形变的初始基准。重复把已有形变当基准再加增量，构成没有上限的递推，
因此单次动画通过并不证明多次中断安全。视觉续接和尺寸限界是两个必须同时满足的不变量。

已核对的实现改为在当前左右边界与目标左右边界之间分别插值；计算及宿主单测覆盖一百余轮
反向中断、每轮多个中段采样及过期回调失效，边界保持在允许包络内。这是计算层的 verified，
不是所有设备的逐帧视觉或光学效果通过。参考中已有轮廓连续移动的证据也排除了将所有切换
都当目标位置重新首现的假设。

## 适用边界

- 适用：可中断、可重定向且尺寸含动态拉伸/缩放的连续 UI 动画。
- 不适用：静态图形只设一次宽度，或不可中断的单次淡入；不要为它们引入重定向状态机。
- 若设计明确允许超调，先定义更大的合法包络；本条不要求所有曲线都没有超调。
- 纯锚点测量错误先按 ap-0155 排查；形变限界不能解决材质折射或平台能力缺失。

## 判定样本

### 路由正例

- **输入**：拉伸动画未结束又反向改选，多次切换后轮廓尺寸累积超过容器。
- **预期**：apply
- **原因**：当前帧携带旧形变，新的目标再次叠加尺寸增量。
- **来源**：observed

### 路由反例

- **输入**：静态指示器只有一个固定宽度，不播放动画，也不能中断或重定向。
- **预期**：skip
- **原因**：没有形变递推链，不应套用可中断动画方案。
- **来源**：constructed

### 执行合格例

- **做法或输出**：从当前显示帧续接；一百余轮反向重定向的中段采样仍在起终边界包络内，旧回调不能恢复旧尺寸。
- **预期**：pass
- **原因**：计算回归同时覆盖连续性、尺寸限界和过期更新，不只验证终点。
- **来源**：observed

### 执行失败例

- **做法或输出**：最终选中项正确，但每次中断仍把距离拉伸叠加到当前已经变宽的轮廓上。
- **预期**：fail
- **原因**：业务终点正确不保证中断期间的尺寸不变量。
- **来源**：constructed

## ✅ 正确

1. 将业务目标、当前显示帧、动画代次分开；无旧轮廓首现与已有轮廓移动分支分别建模。
2. 重定向时读取当前真实显示帧，作为新动画起点；不先重置到旧稳态。
3. 对需要连通拉伸的轮廓，分别计算边界：

   ~~~text
   left  = startLeft  + (targetLeft  - startLeft)  * leftProgress
   right = startRight + (targetRight - startRight) * rightProgress
   width = right - left
   center = (left + right) / 2
   ~~~

   两个边界进度均应有界，且必须另验 left <= right。不同曲线可产生前后缘时差，但不能因此
   丢失合法边界。高度/缩放峰值也应有独立上限，不能每次中断都提高上限。
4. 每次重定向、取消或宿主尺寸变化都使旧代次失效；过期逐帧与完成回调均不能写回。
5. 覆盖首帧连续性、正向/反向/跨目标、中段/终点、重复中断、取消和尺寸变化；计算测试
   与连续录屏各自报告，未测的设备视觉保持 inconclusive。

## 消费与防复发

- 消费者：动画实现 review、纯几何/状态机回归、真实交互视觉验收。
- 必搜：当前尺寸加位移增量、动画 generation/epoch、重定向起点、终点-only 断言。
- 可机械检查：边界包络、正宽高、首尾连续性及旧回调失效；视觉节奏、材质和采样间顿挫仍需运行证据。
- 检索时必须区分路由 apply/skip；计算层 pass 不可升级为整项视觉 PASS。
