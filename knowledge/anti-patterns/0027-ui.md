# 0027 — 修改 UI 时删除业务逻辑

- **平台**:双端
- **lint 状态**:难静态扫描，人工 review

## ❌ 错误

UI 重构时把 onClick / observe / dispatch 一起删掉，"反正后面再加"。

## 为什么错

业务逻辑分散在多处（Activity / Fragment / Adapter / Store），删了很难全部找回。

## ✅ 正确

- 修改 UI 前先 grep 出所有业务逻辑（onClick / observe / collect / setOnRefreshListener）
- 标记为"保护区"
- 只改样式部分（布局 / 颜色 / 字号 / Token）

## lint 状态

- ❌ 无法静态扫描；UI 重构 task 前必 grep 业务回调清单作为保护区
