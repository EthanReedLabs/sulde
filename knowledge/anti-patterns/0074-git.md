# 0074 复合命令 `&&` 链 + 主目录污染 → git 卡死

- **平台**:双端
- **复发次数**:1

## ❌ 错误

```bash
# 一行串 5+ 步，hook 拦截后还硬塞，导致连锁失败
./gradlew compile && git add -A && git commit -m "..." && git push && git checkout develop && git merge ...
```

## 为什么错（实战连锁错误）

1. `git add -A` 在主目录 develop 上加了未提交改动 → 主目录被污染;
2. 想 `worktree remove` → "contains modified files" 拒绝;
3. 想 `merge` → "local changes would be overwritten" 拒绝;
4. 想 `branch -d` → "not fully merged" 拒绝;
5. 错误链式放大,工作树和分支同时卡死。

## ✅ 正确：每步独立执行，看结果再走下一步

```bash
# Step 1：进入 worktree
cd .worktrees/{user}-fix

# Step 2：先看状态
git status

# Step 3：编译验证（独立命令）
./gradlew :feature-xxx:compileDebugKotlin

# Step 4：commit（具体文件，不用 git add -A）
git add specific/file.kt
git commit -m "fix: 具体改了什么"

# Step 5：回主目录
cd ../..

# Step 6：确认主目录干净
git status   # 必须是 "nothing to commit"

# Step 7：merge
git checkout develop
git merge dev/{user}/fix --no-ff -m "merge: ..."
```

**如果某步失败(hook 拦截 / 编译错 / 冲突):立即停止,报告状态,让用户决定。**
