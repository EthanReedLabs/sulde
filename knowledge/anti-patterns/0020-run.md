# 0020 — 长时工作流链式触发新 `.run`

- **平台**:iOS(TCA;MVI 同理)

## ❌ 错误

```swift
.run { send in
    let task = try await client.submit(req)
    await send(.submitted(task))           // 触发新 .run 轮询
}

case .submitted(let task):
    return .run { send in                  // ❌ 链式 .run,每次切换上下文
        for try await status in poll(task) {
            await send(.statusUpdated(status))
        }
    }
```

## 为什么错

链式 `.run` 每环切换 Effect 上下文 → 取消语义 / 生命周期难追踪,中途失败回滚困难,长时工作流(提交→轮询→完成)被切成多段易漏处理。

## ✅ 正确

单个 `.run` 内 `for await` 平铺:

```swift
.run { send in
    let task = try await client.submit(req)
    await send(.submitted(task))
    for try await status in poll(task) {   // ✅ 同一 .run 内
        await send(.statusUpdated(status))
        if status.completed { break }
    }
}
```
