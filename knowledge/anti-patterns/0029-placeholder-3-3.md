# 0029 — 给终端发指令时让用户手动转述差异

- **平台**:协调端协作纪律
- **lint 状态**:难静态扫描，人工 review

## ❌ 错误

```
（协调端）"我看到 Android 截图和设计稿差异有：1. Tab 是 3 个不是 2 个 2. ..."
（用户复制粘贴到 Dev 终端）
```

## 为什么错

浪费用户时间 / 信息丢失 / 终端没有自主能力。

## ✅ 正确

- 协调端只做协调，不替终端做事
- 让 Dev 终端自己 Read 截图 → 自己对比 → 自己修
- 协调端给"指令"，终端执行"动作"

## lint 状态

- ❌ 无法静态扫描；协调端给 Dev 写 task 时让 Dev 自读截图/设计稿对比，不人肉转述
