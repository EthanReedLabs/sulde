# 0007 — 字号既用 sp 又用 dp 混乱

- **平台**:Android

## ❌ 错误

底栏文字用 sp(被系统字号缩放变形)/ 正文用 dp(无障碍场景下用户放大字号无效)。

## ✅ 正确

- **结构性文字(底栏 / Tab / 状态栏标签)**:固定 dp,不随系统字号缩放,保证结构稳定
- **内容性文字(正文 / 标题 / 描述)**:sp,允许用户缩放(无障碍)
- 在统一 Typography 定义里区分:`tabLabel: 13.dp` vs `body1: 16.sp`

**原则**:结构=dp,内容=sp,语义二分,别混用。

## lint 状态

- ⏳ 部分可检:可扫结构性组件(底栏 / Tab)是否误用 sp,但需人工判定语义类别。
