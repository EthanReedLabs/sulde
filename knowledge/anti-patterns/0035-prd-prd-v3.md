# 0035 — 协调端任务书引用旧版 / 简版 PRD 而非最新详版 PRD

- **平台**:协调端 task md 写作
- **复发次数**:0
- **lint 状态**:无法静态 lint，协调端任务书写作前必 grep 最新 PRD 核对

## ❌ 错误

任务书引用旧的简版 PRD 表述（如"首页是多类型 feed 混排：作品/模板/榜单 + Banner 瀑布流"），源自早期签约简版 PRD。

## ✅ 正确

引用最新详版 PRD 定义（如首页是竖滑视频流 + 几个核心动作，无 Banner、无瀑布流）。

## 为什么错

- 简版 PRD 是签约基准，已被详版 PRD 扩展覆盖
- 详版把核心页面形态改掉是核心产品设计决策
- 协调端任务书引用旧版本 → 下游 Dev 要么按任务书违反 PRD，要么按 PRD 违反任务书，两难

## 影响

- Dev 选"按最新 PRD + 告警协调端"是唯一正确做法
- 协调端须对对外文档做 grep 核对，剔除简版 PRD 遗留表述

## lint 状态

- ❌ 无法静态 lint；协调端任务书写作前必 grep 最新 PRD 章节核对
- 数据来源优先级已声明"详版优先于简版"，但任务书模板落地需执行
