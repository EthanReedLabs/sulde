# 0079 长时轮询固定间隔死循环

- **平台**:双端
- **复发次数**:0

## ❌ 错误

```kotlin
while (true) {
    delay(5_000)  // 固定 5s 间隔 / 永不停止
    val status = api.poll(taskId)
    if (status.completed) break
}
```

## 为什么错

进度初期变化快需要短间隔,进度后期变化慢应拉长间隔;无最大重试 / 无取消则永不停止。

## ✅ 正确

自适应间隔(如 5s → 8s → 3s)+ 最大重试次数 + 任务取消时立即停。
