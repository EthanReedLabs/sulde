# NNNN — 规则必须自带边界声明(禁什么 + 不禁什么 + 判据)

- **平台**:跨平台(任何写给他人或 agent 长期执行的规则、法典、纪律条款通用)

## ❌ 错误

把规则写成纯禁令句——"禁止 X"——就收笔。不写这条禁令**不禁什么**,也不给"判定手上这件事是否落入禁区"的判据。

典型形态:一次事故后为止损而立的条款,只把事故里那个特征词写进禁令("禁止再走 X 这类通道"),没有说明构成违规其实需要几个条件同时成立。后来执行者遇到一个只沾了其中一个特征、并不构成原风险的合法做法,照样按规则拦下。

## 为什么

- **禁令句凝固的是事故,不是边界**:规则诞生于一次具体情境,作者当时脑中有边界,但落到文本里只剩下禁令。执行者继承的是规则出生时的创伤,不是当时的判断力。
- **信息缺失时,尽责的执行者一定从严**:后来的执行者(人或 agent)拿不到原始情境,只能按字面最宽的解释适用。越是认真遵守规则的执行者,越倾向 over-block——从严不会被指责,放行才会。
- **过度适用是无声失败**:被误杀的是合法形态,不会报错,只表现为"这条路走不通"而被悄悄绕开,代价以"本该做却没做的事"形式沉在水下。规则作者观察到的却是"规则被遵守了",反馈回路就此断裂。
- **约束范围单调扩大**:一条只有禁令的规则,每次被援引都可能再宽一点,而没有任何机制把它收回来。时间越久,实际管辖面积离作者本意越远。

## ✅ 正确

凡是要写进长期文档、会被别的执行者独立援引的规则,必须三件齐备:

1. **禁什么**——把构成违规的要件写成"以下条件**同时**成立"的合取式,而不是抛一个特征词。合取式天然划出了边界:少一个条件就不违规。
2. **不禁什么**——显式点名最容易被误伤的那个合法形态,并说明它为什么不落入禁区。这一条常常反过来是被鼓励的形态,不写就会被规则连坐。
3. **判据**——给一组当场就能回答的问题(通常 2-4 问),让执行者自行判定手上这件事在不在禁区内,而不必回溯规则的历史或去问作者。

配套做法:

- 后补的边界声明**标注日期或版本**,让读者知道规则演进过。
- 把"规则被过度适用一次"当作**补边界声明的触发信号**,而不是重申禁令的信号——同一条规则被误用,说明缺的是边界不是力度。
- 边界声明是规则的一部分,不是注释;删掉禁令的解释可以,删掉边界不行。

判据一句话:**一条规则若回答不了"什么情况下它不适用",它就还没写完。**
