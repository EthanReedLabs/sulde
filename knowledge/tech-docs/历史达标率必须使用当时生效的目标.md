# 历史达标率必须使用当时生效的目标

## 原则

目标可以随阶段、能力和用户选择变化。历史事实必须与事实发生当天生效的目标比较，不能用当前目标重新解释整个历史，否则目标提高会让过去成绩变差，目标降低则会虚增过去达标率。

## 对齐算法

1. 加载统计区间结束前的所有目标版本。
2. 按本地生效日期和创建顺序排列。
3. 对每条按本地日期记录的事实，选择生效日期不晚于事实日期的最新版本。
4. 每个指标只有在当天同时存在目标和实际值时才进入达标分母。
5. 平均实际值仍按所有已记录事实计算，不因缺少目标而删除记录。

本地日目标应按本地日期对齐，不应混用版本关闭时的 UTC 墙钟时间。

## 验证

构造区间中途调整目标的测试：调整日前的事实按旧目标评估，调整日及之后按新目标评估。蛋白质、碳水、脂肪等可选指标应分别建立自己的可比较日分母。
