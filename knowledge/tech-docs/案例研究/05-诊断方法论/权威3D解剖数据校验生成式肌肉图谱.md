# 权威 3D 解剖数据校验生成式肌肉图谱

## 场景

训练、康复和健康产品常用生成式图片批量制作肌肉示意图。生成结果即使视觉统一，也可能出现三类独立错误：名称对应错误、功能肌群成员不完整、选区边界偏离真实解剖结构。只做人工抽图或只检查文件名，无法证明整套图谱正确。

权威 3D 数据集可提供概念 ID、层级关系、表示 ID 和共享坐标系网格。它适合作为几何参考，但不能直接替代医学审核，也不一定覆盖产品所需的全部肌肉。

## 两层验证模型

### 1. 分类与群体对应

先把每个产品目标分类为：

- `atomic`：单块肌肉；
- `compound`：由多块肌肉构成的功能肌群；
- `regional_subdivision`：同一肌肉的区域或分束；
- `unsupported`：参考数据中没有足够具体的表示。

映射记录必须保存产品目标、官方概念 ID、表示 ID、元素网格 ID 和成员列表。功能肌群不能虚构成一个官方对象；分束也不能用整块母肌肉网格冒充。名称匹配只接受精确名称或经过审计的同义词，不能依赖模糊包含关系自动放行。

覆盖结果至少区分：完整、部分、未解析、不支持。参考数据只有腹外斜肌而产品目标是“腹斜肌群”时，应标记部分覆盖，不能因为满足最低一个成员就写成完整验证。

### 2. 几何边界

不同人体模板的体型、姿态和取景不同，原始像素 IoU 没有意义。合理流程是：

1. 从官方概念解析到实际网格元素；
2. 利用共享 3D 坐标系生成标准前后视正交投影；
3. 从待测图片提取目标选区掩膜；
4. 将双方注册到统一人体坐标；
5. 比较上下边界、左右侧、组件数量和归一化轮廓；
6. 输出诊断图和机器可读指标。

全身图可使用人体高度归一化后的上下边界误差。双侧或多成员肌群应先按连通组件匹配，再比较各组件归一化形状，避免手臂间距或站姿差异制造假失败。

局部放大图和深层肌肉没有可靠的全身注册关系时，不应自动打分。它们必须进入区域注册和专家审核队列。

## 常见误区

1. **名称正确等于图形正确**：分类通过只能证明对象选对，不能证明边界准确。
2. **直接比较两张全身图**：不同人体比例和姿态会让 IoU 失真。
3. **用母肌肉代替分束**：例如上、中、下束需要对应官方区域，而不是重复整块肌肉。
4. **最低覆盖冒充完整覆盖**：功能组缺成员必须显式标记 partial。
5. **数据集缺失时猜边界**：应转为 unsupported，并引入另一权威来源或专家标注。
6. **自动指标直接成为发布许可**：几何脚本是筛查工具，不是医学认证。

## 工程门禁

每次资源更新后自动检查：

- 目标数与映射数一致；
- 所有概念、表示和元素 ID 都能在固定版本数据中解析；
- 不支持集合未经审查不得静默变化；
- 生成图片的尺寸、哈希和目标色掩膜有效；
- 自动比较范围完整且无技术失败；
- 人工复核项不为零时，发布资格保持 false；
- 数据集许可和 attribution 随产物保留。

确定性脚本应重新生成报告，而不是依赖人工维护统计数字。诊断图应同时展示官方轮廓与待测轮廓，便于区分坐标错误、姿态差异和真实边界错误。

## 自动修正失败案例

校验发现偏差后，修正流程应先生成候选目录和修正前快照，不直接覆盖正式资产。一次失败实践把官方正交投影按整个人体外接框线性缩放到产品母版，并用同一投影重新校验。脚本得到全部通过，但人工叠加检查发现肩胛、骨盆、肌肉止点和局部肢体比例明显错位。

根因是验证闭环使用了同一个几何源：重绘蒙版由官方投影生成，验证器又拿它与该投影比较。“通过”只证明生成和验证代码自洽，没有证明投影与产品图中的实际人体解剖对齐。

整个人体外接框只能约束全局宽高，不能作为肌肉级注册。可靠自动修正至少需要：

1. 两套人体共享的骨性和肌肉附着点，并执行分区或非刚性注册；
2. 与产品母版同源的像素级人体/肌肉分区；
3. 每个区域的人工控制点和叠加图审批。

另一个陷阱是用接近背景色的像素阈值裁剪官方网格。浅色肌腱可能与背景连通，导致连续肌肉被错误拆段。人体颜色阈值不应充当解剖边界。

发现错位后必须恢复原图、哈希和状态，关闭自动 apply，并把失败候选保留为证据。自动评分与视觉/专家门禁要相互独立，禁止用自生成结果给自己验收。

## 可迁移结论

权威数据集不是“给生成图片盖章”的工具，而是建立可审计证据链的参考层。高质量图谱需要把分类真值、几何真值、来源覆盖和发布决策拆开。无法验证的对象应保持未知，自动通过的对象仍需在产品语境下接受最终专家审核。
