# 用户展示与业务门禁必须复用同一估算器

当系统用预计时间、成本或负荷做业务门禁时，页面不能另写一套近似计算。否则用户看到的值可能合规，保存时却被拒绝，或页面承诺的时间与实际处方不一致。

将估算器放在共享领域层，生成校验、手动编辑确认和最终展示都调用同一函数。UI 只负责格式化，不复制公式。测试使用包含多个项目和不同数量的代表性处方，固定总量与取整行为。
