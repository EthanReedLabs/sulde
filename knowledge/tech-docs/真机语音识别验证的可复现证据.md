# 真机语音识别验证的可复现证据

> 适用于在真机上验证端侧或云端语音识别（STT/ASR）链路是否真正打通的场景。目标是让"识别可用"这一结论具备可复现、可归档、可回归的证据，而不是依赖一次人工朗读后的口头结论。

## 一、问题：人工说话不是可复现的测试输入

真机语音链路的常见验证方式是：人对着设备说一句话，看界面是否出现文字。这种验证有三个结构性缺陷：

- **输入不可复现**：每次朗读的语速、音量、口音、环境噪声都不同，识别失败时无法区分是模型问题、音频采集问题还是这次念得不好。
- **证据不可归档**：结论只存在于验证者的记忆里，回归时无法与上一次做逐字比对。
- **无法自动化**：任何需要人在场的步骤都会退化为"下次再说"，最终变成长期未验证。

识别链路本身由多个独立环节串联：麦克风权限与采集、音频格式与采样率、模型或服务加载、解码与流式输出、文本回填 UI。任何一环断裂都表现为"没有字"，因此需要一个输入端确定的探针来切分责任。

## 二、方法：用本机 TTS 回放构成声学回路

在同一台设备上用系统或应用内的文本转语音播放一段**预先固定的目标语料**，让设备麦克风采集自己扬声器发出的声音，形成 speaker → air → microphone → STT 的完整声学回路。

这样得到的是一个确定性输入：

1. 语料文本是常量，可以写进测试清单并长期复用；
2. 每一轮的期望输出已知，转写结果可与期望文本做逐字或字错率比对；
3. 验证不需要人在场，可作为真机自检脚本的一步反复执行；
4. 失败时可直接对照"播放了什么 / 采集到什么 / 转写出什么"三段证据定位断点。

落地要点：

- 语料应覆盖短句、长句、含数字与专有名词的句子，各自单独一轮，不要拼成一大段。
- 播放前后各留静默间隔，避免录音起止被截断，也便于在日志中按时间戳切分轮次。
- 播放音量、设备静音开关、是否插入耳机都会改变回路，必须作为环境参数记录在证据里。
- 每轮至少记录：轮次标识、目标文本、播放开始与结束时间、采集到的音频时长与非静音能量、最终转写文本、耗时。

## 三、静音与环境音轮次是失败路径证据

验证过程中经常出现这样的轮次：TTS 没有实际发声、系统静音、麦克风被其他进程占用，或者采集到的只有环境底噪。**这类轮次不应删除或重跑覆盖，而应作为失败路径证据保留。**

理由是：

- 它们证明了链路在"无有效语音输入"时的行为——是返回空串、返回幻觉文本，还是抛错。返回幻觉文本是必须暴露的严重缺陷，只有静音轮次能发现它。
- 它们把"识别失败"细分为"没采到声音"与"采到了但转写不出"，这是两个不同的责任域，前者归音频采集与权限，后者归模型与解码。
- 丢弃失败轮次会让证据集只剩成功路径，回归时无法证明失败分支仍被正确处理。

因此证据表应同时包含预期成功轮次与预期失败轮次，并对失败轮次声明期望行为（例如：静音输入必须产出空结果且不触发下游动作）。

## 四、验证矩阵

| 输入 | 环境 | 期望 |
|---|---|---|
| 固定短句回放 | 正常音量、无耳机 | 转写与目标文本一致或字错率低于阈值 |
| 固定长句回放 | 正常音量 | 流式输出分段到达，最终文本完整 |
| 含数字/专名句回放 | 正常音量 | 关键 token 正确，允许其余误差 |
| 无播放（纯静默） | 安静环境 | 空结果，不产生幻觉文本，不触发下游动作 |
| 无播放（仅环境噪声） | 有背景音 | 空结果或明确的低置信度，不误触发 |
| 播放中途取消 | 正常音量 | 采集与解码资源释放，无残留会话 |

## 五、边界与不可替代之处

TTS 回放是**可复现性探针**，不是真实用户场景的替代：

- 合成语音在音色、韵律和噪声特性上比真人规整，识别率通常偏高。回放通过只证明链路打通，不能作为准确率指标对外声明。
- 真实口音、远场距离、多人同时说话、移动中的风噪等场景仍需真人抽测。
- 回声消除与降噪策略可能把"设备自己播放的声音"判为回声抑制掉，导致回放路径失败而真人说话正常。出现这种情况说明探针受被测系统的回声消除影响，应改用外部播放设备或旁路该处理，而不是据此判定 STT 不可用。

## 六、可迁移原则

1. **凡是依赖人类实时动作的验证，都要找到一个确定性输入替身**：语音用 TTS 回放，触控用自动化注入或定时触发，网络用受控故障注入。替身的价值在于让失败可复现。
2. **成功路径与失败路径的证据同等重要**：只留成功轮次的证据集无法证明系统在异常输入下不误动作。
3. **证据要能切分责任域**：单一"没结果"的结论无法归因，必须同时留下输入端、采集端和输出端三段可核验记录。
4. **探针的通过条件与产品的质量指标是两回事**：链路可用性可以自动验证，识别准确率必须用真实分布的样本单独评估。
