# 调整入口应出现在用户发现问题的上下文

底层已有调整能力、其他页面已有入口，不代表用户旅程闭环。用户通常在看到具体处方、器械要求或疼痛提示时才决定调整，因此入口应出现在该上下文中。

上下文入口必须复用同一领域服务和审核规则，不能复制一套弱校验逻辑。先完成持久化和审计，再导航到替换后的对象；失败时留在原页面并显示可恢复错误。若新页面取代旧对象，应替换当前导航目的地，避免返回键回到已失效状态。
