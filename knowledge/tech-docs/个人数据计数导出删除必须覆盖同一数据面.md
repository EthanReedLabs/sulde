# 个人数据计数导出删除必须覆盖同一数据面

## 原则

隐私控制中的“数据数量”“导出我的数据”和“删除我的数据”必须覆盖同一组个人数据表。任何只进入计数和删除、却不进入导出的表，都会让用户无法取得自己的完整数据；反向遗漏则会造成删除不彻底。

## 实施约束

- 新增个人数据表时，同时登记计数、导出和删除路径。
- 导出优先从运行时 schema 获取列，避免字段迁移后手写序列化遗漏新列。
- 静态动作目录、模型包和协议资源不属于用户生成数据，应明确排除。
- 删除顺序遵守引用关系；导出与计数可以使用一致性快照。

## 验证

为每类新增个人数据至少写入一条记录，断言导出包含该表和关键状态，并断言导出总行数等于个人数据计数。删除测试再确认所有个人表归零、静态目录仍保留。
