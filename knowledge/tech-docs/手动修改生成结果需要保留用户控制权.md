# 手动修改生成结果需要保留用户控制权

生成阶段可以将时间、剂量等预算设为硬门禁；用户手动修改时不应静默突破预算，也不宜直接禁止有意安排。

推荐流程：复用生成阶段同一确定性估算器，在持久化前计算超限项并展示具体对象、估算值和预算值。首次操作不得写库；只有用户明确选择继续后才持久化。取消后保留草稿供继续调整。

测试必须分别证明未确认时 repository 调用次数为零，以及确认后恰好写入一次。这样同时满足安全约束、可解释性和用户最终控制权。
