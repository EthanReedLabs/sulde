# 功能目录必须连接主工作流

## 原则

搜索、筛选和详情完整的功能目录，如果用户选中条目后不能进入实际任务，仍然只是只读资料库。目录必须把条目标识和必要参数传入产品的主工作流。

## 正确连接方式

1. 在详情上下文中提供清晰的主操作。
2. 就地收集进入下一步所需的最少参数，例如目标次数或时长。
3. 复用已有准备流程，不从目录直接绕过安全、权限、器械或兼容性检查。
4. 导航必须保留稳定的条目标识与用户参数。
5. 离开详情时停止语音、媒体播放等临时资源。

## 验证

- 选中的条目 ID 在目标页面保持一致。
- 用户设置的参数没有被默认值覆盖。
- 参数边界由控件和业务层共同约束。
- 返回、关闭和开始操作都会正确清理临时资源。
- 主工作流原有的准备与安全门禁仍然执行。

复用目录数据源比为不同入口维护快捷动作副本更可靠；快捷入口可以存在，但必须同时提供进入完整目录和主工作流的路径。
