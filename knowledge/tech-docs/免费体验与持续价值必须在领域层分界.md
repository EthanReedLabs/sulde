# 免费体验与持续价值必须在领域层分界

订阅门槛不能只隐藏按钮，也不能阻止用户访问自己的数据。应区分一次性建立信任的免费能力和持续产生专业判断的订阅能力。

训练计划场景中，第一份基础周计划可免费生成；已有计划后的持续重规划需要 Coach。查看、执行、手动编辑、导出已有计划不受限制，生成失败重试也不能被误判为付费操作。

规则必须落在领域或 ViewModel 边界并由 UI 解释，商店交易 entitlement 是唯一权益真值。本地布尔值和仅 UI 付费墙都不能作为安全边界。
