# 动作示范素材必须精确匹配变式

动作教学不能按运动模式共用一张泛化图片。徒手深蹲、杠铃背蹲和高脚杯深蹲的器械、负荷位置、准备方式和安全要求不同，错误回退会直接误导用户。

每组素材应固定人物、服装、器械、负重、机位、裁剪和光线，只改变动作阶段。至少覆盖起始、离心过渡、关键底部/终点和向心返回。生成后逐帧检查人体完整、器械一致、关节轨迹合理，再建立精确 exercise id 映射；无匹配素材时宁可不展示，也不能回退到相似动作。

播放器能力与素材覆盖率分开验收。支持播放、慢放、镜像不等于动作目录已覆盖，矩阵必须记录 `已审核素材数/目录动作数`。

2026-07-15 覆盖进度：已审核杠铃背蹲、徒手深蹲和高脚杯深蹲，覆盖 `3/21`。高脚杯深蹲固定单只哑铃竖直贴胸，箱式深蹲继续保持无素材状态，避免跨变式回退。

同日补齐自重箱式深蹲后覆盖为 `4/21`。箱式素材必须让同一训练凳在所有阶段保持位置一致，并明确呈现臀部触凳与主动起身；不能用普通徒手深蹲画面替代。

补齐站姿哑铃弯举后覆盖为 `5/21`。标准弯举必须显示旋后握法和掌心向上，锤式弯举必须显示中立握法；两者即使轨迹相近也不得共用素材。

补齐锤式弯举后覆盖为 `6/21`。验收中必须逐帧确认哑铃竖直、掌心相对和拇指朝上，并继续禁止向弹力带弯举跨器械回退。

补齐弹力带弯举后覆盖为 `7/21`。弹力带素材必须逐帧验证锚点、带路与张力连续，避免生成图出现悬空、断裂或不同阶段锚点变化；不得用哑铃素材替代。

补齐站姿哑铃侧平举后覆盖为 `8/21`。验收必须确认抬臂方向位于身体侧向肩胛平面、手略低于肘、顶峰不超过肩高，且不与前平举、推举或弹力带侧平举共用素材。

补齐弹力带侧平举后覆盖为 `9/21`。除了侧向轨迹和肩高上限，还必须确认双脚锚点与腿外侧带路在所有阶段连续；不得向哑铃侧平举或过顶推举回退。

补齐站姿杠铃过顶推举后覆盖为 `10/21`。目录器械定义必须先参与素材选择；杠铃推举需确认锁骨起始、近面垂直路径、头顶堆叠锁定和无腿部借力，不得回退到坐姿哑铃推举。

补齐坐姿哑铃推举后覆盖为 `11/21`。四阶段必须固定高靠背凳角度，确认背部贴靠、双脚落地和双哑铃垂直路径；不得回退到站姿杠铃或带旋转轨迹的阿诺德推举。

补齐坐姿阿诺德推举后覆盖为 `12/21`。必须清晰呈现掌心朝内的面前起始、上推外旋和掌心向前锁定；如果旋转轨迹不可辨识，就不能视为该变式已覆盖。

补齐杠铃俯身划船后覆盖为 `13/21`。验收必须确认髋铰链、膝角和躯干角度在拉动阶段保持稳定，杠铃贴近身体拉向上腹，避免将抬身借力、硬拉或胸托划船误作该动作。

补齐胸托哑铃划船后覆盖为 `14/21`。必须固定上斜凳角和脚位，确认胸部全程贴垫、双侧哑铃同步拉向下肋；不得回退到无支撑杠铃或单臂哑铃划船。

补齐单臂哑铃划船后覆盖为 `15/21`。四阶段必须固定同一手膝支撑侧和单只工作哑铃，确认肩髋方正、躯干抗旋转；不得回退到双侧胸托或弹力带划船。

补齐站姿弹力带划船后覆盖为 `16/21`。必须固定胸高锚点、水平双带路径和交错站姿，确认手柄拉至下肋且躯干不后仰；不得误作弯举、面拉或器械划船。

补齐哑铃罗马尼亚硬拉后覆盖为 `17/21`。验收必须确认髋向后、膝角基本稳定、胫骨近垂直、哑铃贴腿和脊柱中立；明显屈膝下蹲或哑铃离身时不能视为该动作。

补齐标准俯卧撑后覆盖为 `18/21`。验收必须确认头肩髋踝维持直线、肘部约 30-45 度、胸部接近地面且身体整体升降；塌腰、撅髋、跪姿或上斜版本不得回退使用。

补齐自重反向箭步蹲后覆盖为 `19/21`。四阶段必须固定前侧工作腿和后迈腿，确认前脚跟落地、前膝跟随脚尖、后膝接近地面且骨盆方正；不得误作前向箭步或分腿蹲。

补齐自重臀桥后覆盖为 `20/21`。顶峰必须由髋伸形成肩髋膝连续线，双脚和膝部稳定、骨盆水平、肋骨受控，不能用腰椎过伸替代；宽幅素材还必须裁掉无效空白，保证移动端关节可读。

补齐前臂平板支撑后目录覆盖达到 `21/21`。静态动作使用“跪姿设置、单腿后伸、完整支撑、稳定保持”检查序列，不能伪造动态重复；完整位需确认肘在肩下、头肩髋踝成线。测试必须逐项覆盖全部目录 ID，并断言未知 ID 不发生素材回退。
