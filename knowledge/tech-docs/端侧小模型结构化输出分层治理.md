# 端侧小模型结构化输出分层治理

## 问题原型

端侧小模型即使被要求“只返回 JSON”，仍可能输出思考标签、Markdown fence、前后解释、
字段拼写偏差、截断对象或多个对象。单纯加重 prompt，或每次失败都再让模型修一次，会
增加延迟和随机性，仍不能建立可验证的数据边界。

## 根因与证据

根因是把 prompt 当成协议、把概率模型当成确定性 parser。固定语料已观察到 think/fence 包装、
字符串内花括号、多个对象、字段 typo 与截断输出；贪婪正则和无限模型修复会分别误截内容并放大
时延。状态机提取、白名单归一化、schema/语义校验和至多一次修复可以逐层度量并安全失败。

## 适用边界

- 适用于端侧或远端生成模型向业务层输出 JSON、动作码、计划或其他结构化协议的场景。
- 自由文本只需展示时不必强制 JSON，但仍应在源边界过滤内部标记和控制 token。
- 白名单归一化只允许无语义歧义的已知结构差异；缺失业务值必须失败，不能猜补。

## 路由正例

- **输入**：小模型偶尔返回 think 标签和 fenced JSON，业务用贪婪正则截取后直接入库。
- **预期**：apply
- **原因**：概率包装、非确定性提取和缺少 schema 门禁同时存在。
- **来源**：observed

## 路由反例

- **输入**：模型只生成供用户阅读的自由文本，不进入结构化业务字段或动作执行。
- **预期**：skip
- **原因**：没有结构化协议消费端，应路由到用户可见文本输出治理。
- **来源**：constructed

## 执行合格例

- **做法或输出**：状态机提取首个平衡对象，白名单修复已知 typo，schema/语义通过后才持久化。
- **预期**：pass
- **原因**：每层职责可验证，未知偏差 fail closed，模型重试被严格限次。
- **来源**：observed

## 执行失败例

- **做法或输出**：从首个左花括号贪婪截到最后一个右花括号，缺字段时让模型无限自修。
- **预期**：fail
- **原因**：会拼接多个对象、改变字符串内容并产生无界时延，仍没有确定性协议边界。
- **来源**：observed

## ✅ 正确

1. **生成层降低熵**：使用模型明确支持的禁用思考开关（如对应运行时的 `no_think`）、
   低温采样、紧凑 schema、字段枚举和停止条件。控制项必须以当前 runtime 实测为准，
   不能把某个模型的控制 token 当成跨模型协议。
2. **确定性提取**：先移除已知的 think/fence 包装，再用状态机提取第一个平衡 JSON 对象；
   状态机必须识别字符串、转义字符与嵌套括号，禁止用贪婪正则从第一个 `{` 截到最后
   一个 `}`。
3. **白名单归一化**：只修复有实证、无语义歧义的结构性偏差，例如固定字段 typo、已知
   枚举别名或多余尾逗号。每条规则版本化并计数；禁止猜测缺失业务值或悄悄改写含义。
4. **确定性校验**：依次执行 JSON parse、schema、枚举/范围和跨字段语义校验。只有全部
   通过的对象才能持久化或驱动业务；prompt 约束不是最终门禁。
5. **限次修复与降级**：校验失败时，把结构化错误回喂模型至多一次；仍失败就返回明确
   错误或安全降级，不进入无限修复循环。常见稳定错误应优先沉淀为 normalizer，而不是
   长期消耗第二次推理。

## 观测与验收

- 分别记录首次通过率、确定性归一化命中率、模型修复成功率、最终失败率和各层耗时；
  不得只报告“最终大多能解析”。
- fixture 至少覆盖：纯 JSON、think/fence 包装、字符串内花括号、嵌套对象、多个对象、
  已知 typo、未知字段、枚举越界和半截 JSON。
- 对每条 normalizer 规则提供正反例，证明只改变获批结构而不改变自由文本内容。
- 模型/量化/runtime 升级后重跑固定语料；若归一化命中率突升，应视为输出契约退化，
  不能因为最终解析仍通过而忽略。

## 判定线

只靠 prompt 保证 JSON、用贪婪正则截对象、任意猜值修补、校验失败仍入库，或无限调用
模型自修，均不构成可靠的结构化输出链路。

## 消费与防复发

- 推理运行时、normalizer、schema validator、持久层和业务动作执行器共享版本化输出合同。
- 每条归一化规则带正反 fixture 和命中指标；模型/量化/runtime 升级后重跑固定语料。
- 最终失败必须是用户可理解的安全降级，原始内部协议只进入脱敏诊断，不进入 UI 或业务字段。
