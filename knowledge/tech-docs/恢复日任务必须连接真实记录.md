# 恢复日任务必须连接真实记录

## 原则

恢复日不能只是空页面或复选框集合。用户需要知道为什么恢复、今天具体做什么、下一次何时训练以及需要准备什么。需要反馈数据的任务只有在结构化记录成功保存后才能算完成。

## 页面信息

- 恢复原因，说明它与当前计划或身体状态的关系。
- 可执行的低强度行动及明确目标。
- 下一次训练日和主要训练内容。
- 从正式动作目录推导并去重的器械准备清单。
- 身体反馈入口，而不是无数据支撑的“已完成”复选框。

## 完成语义

步行、活动度等行为任务可以由用户直接确认和撤销。精力、压力、酸痛、睡眠等反馈任务应打开结构化表单，保存成功后再更新任务状态；取消或保存失败不能增加完成度。

恢复任务可以进入计划依从性，但健康数据同步本身不是用户任务，不能因为系统自动同步成功而增加完成度。

## 验证

测试应覆盖最近未来训练日选择、过去日期排除、动作名称来源、器械去重，以及反馈保存与任务完成的先后关系。
